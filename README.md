# CarbonGlobe website

Project page for **CarbonGlobe: A Global-Scale, Multi-Decade Dataset and Benchmark for Carbon Forecasting in Forest Ecosystems** (NeurIPS 2025, Datasets & Benchmarks).

**https://zhwang0.github.io/carbon-globe-website/**

- Paper: [NeurIPS 2025 proceedings](https://proceedings.neurips.cc/paper_files/paper/2025/hash/0b82662b6c32e887bb252a74d8cb2d5e-Abstract-Datasets_and_Benchmarks_Track.html), doi:[10.52202/085713-0261](https://doi.org/10.52202/085713-0261)
- Dataset: [Hugging Face](https://huggingface.co/datasets/zhwang1/CarbonGlobe) and [Kaggle](https://www.kaggle.com/datasets/zhihaow/carbonglobe)
- Code: [zhwang0/carbon-globe](https://github.com/zhwang0/carbon-globe)
- Challenge: [IEEE Big Data Cup 2026](https://www.kaggle.com/competitions/ieee-bigdata-cup-2026-ai-emulation-challenge/overview)
